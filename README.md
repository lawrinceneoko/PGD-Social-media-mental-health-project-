# PGD Mental Health Illness Prediction System

An intelligent mental health prediction system that integrates multimodal behavioral, emotional, and linguistic features using a hybrid Artificial Neural Network (ANN) and Long Short-Term Memory (LSTM) deep learning architecture.

## 📄 Project Documentation
- **Full Research Report:** [`PGD_Mental_Health_Project.pdf`](./PGD_Mental_Health_Project.pdf)

## 🛠️ Key Components
- **`app_mental_api.py`**: Flask web application interface serving the ensemble model.
- **`train_models_api.py`**: Training script for TF-IDF + ANN and Tokenizer + LSTM models.
- **`generate_synthetic_data.py`**: Data generation utility for system testing.
- **`requirements.txt`**: Dependency list for running the application environment.
